# 공개 비행 비교의 물리·수치 검사와 민감도

실행일: 2026-11-07. [최종 설정](public_flight_comparison_report_ko.md)은 검사한 모델 제약과 수치 일치 기준을 만족했다. 그러나 **연착륙은 특정 초기 방향·목표와 이상적 구동기에 조건부**다. 추력 −2%와 구동기 응답 지연을 적용한 시험에서는 충돌했다.

## 시험 조건

입력·제어기·목표·관측을 고정하고 [선언한 범위](../../configs/analysis/flight_sensitivity.yaml)에서 75개 구간 실행과 20개 관측 기준 시험을 수행했다. 질량 상한을 넘는 상승 실행 요청 2개는 거부했고, 정지 발사대의 속력·방향 변경 4개는 적용하지 않았다. 시험 횟수는 성공 확률의 분모가 아니며, 아래 폭은 실제 CRS-11 오차 한계나 신뢰구간이 아니다.

| 항목 | 시험 범위·조건 |
|---|---|
| 초기 총속력 | ±0.277778 m/s. 상승은 정지 유지 |
| 초기 속도 방향 / 기체 자세 | N–D 평면 방향 ±1° / pitch ±1°. 위치·목표·제어기는 고정 |
| 초기 질량 | ±1%. 상승·재진입 시작에 적용하고 이후 회복 질량·RCS 가스는 실제 적분 종료값 전달 |
| 추력 | ±2%. 힘만 변경하고 추진제 유량·유도 모델은 유지 |
| 항력 | 기체·핀 Cd에 공통 ±10%. 양력·압력중심은 유지 |
| 바람 | 북쪽 방향 ±8 m/s |
| 조합 | 질량 +1%·추력 −2%, 질량 −1%·추력 +2% |
| 착륙 구동기 | 이상적 모델을 기존 응답 지연·변화율 제한 모델로 교체. 제어기 재조정 없음 |
| 관측 기준 | 비교용 모의 고도 ±50 m, 모의 표본 시각 ±0.033 s. 원본·초기조건·최종 설정은 유지 |

각 구간의 운동 상태는 독립 초기화하며 회복 구간의 질량 전달 차이는 모두 0 kg다. 임의 잡음·슬로싱 주입이나 재보정은 하지 않았다.

## 물리·수치 검사 결과

다섯 기준 실행과 75개 변형은 기록된 상태·구동기 출력에서 질량·추진제·관성·탱크 용량·추력·변위·공력표·대기 적용 범위 검사를 통과했다. 충돌 궤적도 이 검사를 통과할 수 있으며, 로그 사이의 모든 극값이나 실제 기체 계수를 검증한 것은 아니다. 핀은 중립으로 고정했으므로 큰 편향에서의 공력 유효성까지 확인한 시험도 아니다.

| 검사 | 결과와 범위 |
|---|---|
| 지정 입력의 네 구간 | 독립 DOP853 및 허용오차 강화, 1/0.5/0.25 ms 계산 비교 통과. 최대 위치 차이 약 4.18×10⁻⁵ m |
| 착륙 폐루프 | 2/1/0.5 ms에서 모두 연착륙. 접지 종료 시각 차이 최대 0.001 s |
| 착륙의 기록된 명령 재생 | 초기 상태부터 마지막 기록까지 독립 DOP853 적분. 최대 차이는 위치 9.18×10⁻⁹ m, 속도 2.74×10⁻¹¹ m/s, 질량 3.79×10⁻⁹ kg |

착륙 명령 재생은 별도 좌표계·회전·질량·힘 계산을 사용하며 기록 상태로 중간 재설정하지 않았다. `rtol=1e-10/1e-12` 변화도 기준 안이다. 이는 같은 명령에 대한 운동 계산의 일치이며 제어기·접지 검출의 독립 검증이나 실비행 정확도 검증은 아니다. 모든 변형에서 독립 적분을 반복하지는 않았다.

응답 지연 모델의 시동 중 스로틀이 정상 명령의 최솟값 아래를 지나는 과도응답은 허용했다. 반면 이상적 착륙 모델의 기록 간 평균 변화율은 스로틀 약 **40 s⁻¹**, 짐벌 **0.686 rad/s**로, 응답 제한 모델의 **1 s⁻¹ / 0.35 rad/s**보다 크다. 이상적 모델 안의 오류는 아니지만 동일 궤적의 하드웨어 실현 가능성을 보장하지 않는다.

## 구간별 민감도

오차는 기준 실행과 변형이 동시에 제공하는 유효 관측 구간에서 비교하고, 각 실행의 전체 비교 시간도 별도로 기록했다. 조기 종료 뒤를 정지값으로 채우지 않았다.

| 구간 | 주요 결과 |
|---|---|
| 상승 | 초기 pitch ±1°에서 고도 RMSE 3,437.669–6,266.502 m, 바람 ±8 m/s에서 2,102.719–13,341.803 m. 기준 51.277 m에 비해 민감 |
| 재진입 연소 | 초기 방향 ±1°에서 고도 RMSE 116.005–157.461 m. 기준 136.654 m |
| 공력 하강 | 항력 ±10%에서 속력 RMSE 53.931–80.443 m/s. 기준 66.365 m/s |
| 최종 동력 하강 | 항력 ±10%에서 고도 RMSE 223.104–320.843 m, 속력 RMSE 27.502–38.046 m/s. 기준 273.751 m / 32.884 m/s |
| 착륙 | 아래 조건에서 경착륙·충돌 발생. 기준 조건의 성공을 넓은 가정 범위로 일반화할 수 없음 |

### 착륙 결과

분류는 기존 시뮬레이터의 수직·수평 속도·기울기·각속도 기준을 따른다. 총속력 하나만으로 분류하지 않으며, 임무 성공에는 위치·연료 조건도 포함된다. 실제 CRS-11 구조 인증 기준은 아니다.

| 시험 | 접지 총속력 [m/s] | 목표 위치 오차 [m] | 분류 |
|---|---:|---:|---|
| 기준 | 0.998 | 0.455 | 연착륙 |
| 초기 속력 −0.277778 m/s | 2.345 | 0.436 | 경착륙 |
| 초기 방향 −1° / +1° | 3.426 / 3.182 | 3.622 / 3.073 | 경착륙 / 경착륙 |
| 추력 −2% / +2% | 12.539 / 3.262 | 0.299 / 0.499 | 충돌 / 경착륙 |
| 항력 −10% / +10% | 4.154 / 1.482 | 0.425 / 0.478 | 경착륙 / 연착륙 |
| 북쪽 바람 −8 / +8 m/s | 0.958 / 1.101 | 4.952 / 5.650 | 연착륙 / 연착륙 |
| 질량 +1%·추력 −2% | 12.589 | 0.320 | 충돌 |
| 응답 지연·변화율 제한 구동기 | 24.621 | 0.058 | 충돌 |

구동기 교체 시험은 추진제가 남아 있어도 충돌했다. 기준 속력 비교 시간은 6.040초, 이 실패 실행은 4.872초이므로 각 실행의 RMSE만 비교해 개선 여부를 판단해서는 안 된다.

초기 방향을 정할 때 허용한 고도 차이도 별도로 검사했다. **50 m**에서는 일정 방향 가정을 만족하는 해가 없었다. **100 m**에서는 허용 비율의 양 끝과 중간값 모두 연착륙했고 접지 속력은 0.946–1.049 m/s였다. **150 m**에서는 수직인 끝만 연착륙했으며 낮은 끝과 중간값은 각각 9.038, 5.545 m/s로 충돌했다. 초기 계획의 존재가 폐루프 연착륙을 보장하지 않는다. [전체 방향 가정 시험](../../results/verification/public_flight_comparison/reconstruction_20261107/display_tolerance_sensitivity.json)에 보관했다.

### 관측 기준의 영향

비교용 고도에 −50/+50 m를 더하면 착륙 고도 RMSE는 기준 72.712 m에서 119.906/34.593 m로 달라진다. 시각 ±0.033 s에서는 재진입 고도 RMSE가 117.421–162.440 m로 변한다. 이 값으로 원본을 보정하지 않았으며, 실제 기준면·지연이 이 범위 안이라는 뜻도 아니다.

민감도는 어떤 가정이 결과에 영향을 주는지 보여 주지만 실제 잔차의 원인을 식별하지는 못한다. 현재 확인한 것은 **선언한 모델의 계산 일치와 조건부 착륙**이며, 강인한 착륙·실제 구동기 성능·전체 착륙 관측의 재현은 확보하지 못했다.
